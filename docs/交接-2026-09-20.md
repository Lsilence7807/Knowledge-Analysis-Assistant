## 4. 坑

- **PowerShell 数组展平**：`@( @('old','new') )` 会塌成两个字符串，`$pair[0]`/`$pair[1]` 变成「首字符 / 次字符」，整份文档会被按字符替换（本轮踩过：`已`→`有`、`面`→`向`，靠 `git checkout -- docs` 救回）。多组替换一律写 Python 脚本。
- **写入要沙箱外权限**：`docs/`、`README.md` 等**仓库里已存在的文件**被沙箱拦（新建文件不受影响），必须走 `require_escalated`。
- 本机测试必须授权（非沙箱）运行：沙箱内 `tmp_path` 不可写 → 77 ERROR（K-017）。`pytest tests --collect-only -q` 在沙箱内可跑，用来核对用例数。
- 起服务前先看端口：`Get-NetTCPConnection -LocalPort 8017 -State Listen`；旧进程占着端口时新进程会**悄悄退出**，健康检查还通，整轮真链路测的是旧代码。
- 真链路排查用 `curl.exe`（`-s -F "file=@路径"`、`-d '{"json":"…"}'`、`-o NUL -w "%{http_code}"`），别用 `Invoke-RestMethod`。**上传响应的表名字段是 `table`，不是 `table_name`。**
- 本机 `config/local.json` 有页面写入的密钥（profile `local`、`deepseek-flash`，base_url `https://api.deepseek.com`），`.gitignore` 挡住，别提交；测试夹具已隔离它（K-019）。
- 改前端别碰 id 与事件绑定；图表取色集中在 `chartTheme`（已读 `:root` 变量）。
- 动运行时数据前先复制一份：本轮清 `data/meta.sqlite` 的 6 行孤儿 `agent_steps`（K-026）前留了备份在 `%TEMP%\meta-before-orphan-clean.sqlite`。

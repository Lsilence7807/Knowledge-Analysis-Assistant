- 改文件：本机 `apply_patch` 吃不下中文多行补丁（报 “the last line of the patch must be '*** End Patch'”）。整份重写用 `[IO.File]::WriteAllText($绝对路径, $文本, (New-Object Text.UTF8Encoding $false))`，单点改动用精确子串替换。注意 .NET 静态方法**不认 PowerShell 的 `cd`**，路径必须写绝对路径，否则会在仓库根生成 0 字节空壳文件

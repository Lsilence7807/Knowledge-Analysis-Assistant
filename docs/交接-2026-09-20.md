## 4. 坑

- 测试必须授权（非沙箱）运行：沙箱内 `tmp_path` 不可写 → 40+ ERROR（K-017）
- 起服务前先看端口：`Get-NetTCPConnection -LocalPort 8017 -State Listen`；旧进程占着端口时新进程会**悄悄退出**，健康检查还通，整轮真链路测的是旧代码
- 本机 `config/local.json` 有页面写入的密钥（profile `local`、`deepseek-flash`），被 `.gitignore` 挡住，别提交；测试夹具已隔离它（K-019）
- 改文件：本机 `apply_patch` 吃不下中文多行补丁（报 “the last line of the patch must be '*** End Patch'”）。整份重写用 `[IO.File]::WriteAllText($绝对路径, $文本, (New-Object Text.UTF8Encoding $false))`，单点改动用精确子串替换。注意 .NET 静态方法**不认 PowerShell 的 `cd`**，路径必须写绝对路径，否则会在仓库根生成 0 字节空壳文件
- 改前端别碰 id 与事件绑定（`web/index.html` 一个文件里 HTML/CSS/JS 混排）；图表取色集中在 `chartTheme`，加新图类型走同一处

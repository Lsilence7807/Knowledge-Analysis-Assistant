## 4. 坑

- **PowerShell 数组展平**：`@( @('old','new') )` 会塌成两个字符串，`$pair[0]`/`$pair[1]` 变成「首字符 / 次字符」，于是整份文档被按字符替换（本轮踩过：`已`→`有`、`面`→`向`，靠 `git checkout -- docs` 救回）。多组替换一律写 Python 脚本。
- **`docs/` 写入要沙箱外权限**（仓库根与 `web/` 正常）；`apply_patch` 吃不下中文多行补丁（报 “the last line of the patch must be '*** End Patch'”），改用 `[IO.File]::WriteAllText(绝对路径, 文本, (New-Object Text.UTF8Encoding $false))` 或 Python 脚本；.NET 静态方法不认 PowerShell 的 `cd`，路径必须写绝对路径，否则会在仓库根生成 0 字节空壳文件。
- 测试必须授权（非沙箱）运行：沙箱内 `tmp_path` 不可写 → 77 ERROR（K-017）。`pytest tests --collect-only -q` 在沙箱内可跑，用来核对每段用例数。
- 起服务前先看端口：`Get-NetTCPConnection -LocalPort 8017 -State Listen`；旧进程占着端口时新进程会**悄悄退出**，健康检查还通，整轮真链路测的是旧代码。
- 真链路排查用 `curl.exe`（`-s -F "file=@路径"`、`-d '{"json":"…"}'`、`-o NUL -w "%{http_code}"`），别用 `Invoke-RestMethod`：`-Form` 的返回类型与属性取值容易看走眼，本轮因此误判过一次 404。**上传响应的表名字段是 `table`，不是 `table_name`。**
- 本机 `config/local.json` 有页面写入的密钥（profile `local`、`deepseek-flash`，base_url `https://api.deepseek.com`），`.gitignore` 挡住，别提交；测试夹具已隔离它（K-019）。
- 改前端别碰 id 与事件绑定（`web/index.html` 单文件混排）；图表取色集中在 `chartTheme`。
- `data/meta.sqlite` 曾留 6 行孤儿 `agent_steps`（K-026，K-005 之前的历史数据），本轮已清，备份在 `%TEMP%\meta-before-orphan-clean.sqlite`；要动运行时数据先照这个做法复制一份。

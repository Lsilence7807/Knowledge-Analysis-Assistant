## 1. 做了什么

上传 CSV/XLSX/XLS（≤50MB，多 sheet 取首个并在清洗日志注明）→ 清洗（列名归一、类型推断、完全重复行去重、缺失率统计）→ 数据画像（行列数、字段类型、缺失率、枚举样例）→ 手写 SQL（单条 SELECT、只读、10s、5000 行封顶）与描述统计 / IQR+z-score 异常 → 中文提问走 agent 多步工具循环（默认 ≤6 步，每步工具、耗时、返回行数都可查）→ 结果表 + 结构化结论（摘要/发现/异常/建议/置信度/注意事项，数字可回溯）→ 单页前端（上传、选数据集、提问、SQL 折叠、结果表、步骤面板、结论卡片、ECharts 图表）。数据集可删除（DuckDB 表 + 原始文件 + 元数据与流水一起清）。

刻意不做（对应后续阶段）：流式 P17、后台作业 P18、缓存与多轮记忆 P10、语义检索 P14、多模型与回退 P9（页面已能配任意 OpenAI 兼容厂商，但不会自动切换/回退）、Skill P6、知识库 P7、MCP P8、登录与公网 P11、沙箱与指标语义层 P15（桌面包 P12 已取消）、评测与可观测 P16、报告导出 P19、收藏与重导入 P20、多表 join P22、数据源 P23、反馈与配额 P24。

P21 性能与并发契约已完成（后续阶段里先做掉的一段）：所有阻塞调用统一走 `app/exec.py` 的 `run_blocking` 线程池，`GET /bench` 读 `bench/baseline.json` 基线；50 万行聚合实测 p95 0.0619s（预算 1.5s），事件循环心跳 p95 ≤200ms。

## 2. 怎么跑与验收

日常启动：双击仓库根目录的 `启动.cmd`（首次自动建 `.venv`、装 `requirements.lock`、起服务并打开页面）。下面四条是手动口径：

```
& .\.venv\Scripts\python.exe -m uvicorn app.main:app --port 8017      # 页面 http://127.0.0.1:8017/
& .\.venv\Scripts\python.exe -m pytest tests -q                       # 164 passed（全仓库唯一回归口径）
& .\.venv\Scripts\python.exe -m ruff check app tests                  # 质量门，与上面一起跑
& .\.venv\Scripts\python.exe -m ruff format --check app tests
```

测试必须授权（非沙箱）运行：沙箱内 `tmp_path` 不可写 → 40+ ERROR（K-017）。

环境变量：`LLM_API_KEY` 兜底密钥（页面写入的 `config/local.json` 优先，其次 profile 的 `api_key_env`；都没有则提问降级为「只能手写 SQL」，其余功能照常）｜`DATA_DIR=./data`｜`MAX_UPLOAD_MB=50`｜`ENABLE_AGENT=true`（false 走 P3 单跳）｜`AGENT_MAX_STEPS=6`｜`EXEC_MAX_WORKERS=4`（阻塞任务线程池）。模型换哪家：页面配（写 `config/local.json`）或改 `config/models.json`；工具白名单与超时看 `config/tools.json`。

## 3. 扩展契约（能一路长成大系统的全部秘密）

往后加任何阶段只允许三件事：**新建文件**实现能力（按设计文档 §4.1 的路径命名）｜**注册表加一行**（`registry.py` 的 `CAPABILITIES`，或 `tools.py` 里 `register()`）｜**编排层插调用**（只在 `main.py` 插，不进 `nlu.py` / `agent.py` 内部）。v3.0 再补一条：**能用现成框架的用框架**（模块 → 框架映射见 `系统总体设计.md` §11，新增依赖先在那里加一行）；**骨架同理**：新增端点走 `api/routes` + `api/__init__.py`、新增页面走 `frontend/src/routes`、建表走 Alembic、组件先查 shadcn/ui，别手搭（ADR-39/40）。

三条禁令：禁止改已验收阶段的函数体（要改契约先回设计文档登记并同步改验收命令）｜禁止下层 import 上层（`providers/*` 只被 `registry.py` 惰性 import）｜禁止为「以后可能用到」提前加抽象层。

为什么够用：模型调用全在 `llm.py` 一个出口，工具全在 `tools.py` 一张表，能力全在 `registry.py` 一个字典，落盘全在 `db.py` / `store.py` / `ingest.py`——这四处是唯一改动面，其余都是叶子。

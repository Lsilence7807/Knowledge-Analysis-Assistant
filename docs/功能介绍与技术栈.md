# AI 数据分析助手 · 功能介绍与技术栈

面向使用者与评审，不含施工细节；**技术栈一表与代码逐条对齐**（依据 `requirements.txt` 与 `frontend/package.json`），已实现范围与逐文件作用看 `代码台账.md`。契约与阶段计划见 `系统总体设计.md`，当前进度与已知问题见 `代码台账.md`，第一版（MVP）范围见 `最小可用集.md`。

## 1. 一句话定位

上传表格和文档，用中文多轮提问，模型自己规划步骤、调用工具查数与算数，最后给出带数字依据的结论、图表和可导出的报告；Skill、知识库、MCP 插件、模型都可替换，部署形态是公网网页端或本机自用（Windows 桌面端已移出范围）。

## 2. 功能清单

- **数据接入与清洗**：CSV/XLSX/XLS（≤50MB，多 sheet 取首个并记进清洗日志）；PDF/Word 走知识库通道（扫描件 OCR 不做）；自动清洗（列名归一、类型推断、完全重复行去重、缺失率统计、空列提示）+ 数据画像（行列数、字段类型、缺失率、枚举样例）；数据集带版本号（重导入或改清洗规则 +1，问答缓存同步失效）与 schema drift 报告。
- **分析、结论与口径**：模型自主规划多步工具调用（默认 ≤6 步、每步轨迹可查），工具含 SQL、描述统计、异常检测、知识库检索、技能、MCP、受限代码执行、指标口径、报告导出；多跳问题一次问完；每步取数与 `/query` 同口径（≤5000 行），回给模型的超限结果只回摘要与列名；步数用尽返回已完成步骤而不报错。统计含描述统计（计数、去重计数、分位数、均值方差）与 IQR + z-score 双规则异常（标出依据）；结论结构化输出（摘要/发现/异常/建议/置信度/注意事项）且数字可回溯，证据不足写进注意事项而不编造，指代不清先反问；指标语义层集中定义口径（别名、公式、单位、归属人），未定义的指标不臆造公式。表达不了的分析可写 pandas 代码（自定义指标、复杂分箱、时间序列）：独立子进程、临时目录、20s 超时、输出 ≤1MB、import 白名单、只注入当前数据集只读副本——进程级隔离而非容器级，公网多租户需换容器方案。
- **多轮对话与问答复用**：会话内追问支持指代式提问（带最近 6 轮提问与 SQL、最近 2 轮结论摘要）；相同问题命中精确缓存（毫秒级、零模型调用、零成本），同义改写命中语义缓存（复用历史 SQL、结论按当前数据重算）；缓存按「数据集 + 数据版本 + 模型 + 提示词版本」隔离；命中率分精确与语义两栏可查。
- **可扩展与外部接入**：**Skill**（目录技能包 `SKILL.md` + 可选脚本，prompt 型注入上下文、script 型受限子进程执行、可单独启停）；**知识库**（md/txt/pdf/docx，向量召回 20 取 5、答案带出处、embedding 不可用时回退关键词检索）；**MCP 插件**（按配置接标准 server、自动发现工具、白名单调用、崩溃或超时只降级该能力）——三者都可一键关闭。**模型接入**覆盖 OpenAI、DeepSeek、通义千问、Kimi、智谱、Gemini 兼容端点、本地 Ollama；新增厂商通常只改一份 JSON 配置，P5 起也能在页面填 base_url + 模型名 + 密钥（写本机 `config/local.json`，免重启）；按用途分配模型（生成 SQL 用便宜小模型、写结论用强模型）；失败按回退链换备选，全挂给结构化说明；未配密钥的模型界面标不可用。**多表关系**：自动推断关联列（列名同义 + 类型一致 + 值交集采样）并给置信度与候选，确认后才允许 join，未登记的跨表 join 被拒并回传候选。**企业数据库**：只读拉取（配数据源 → 测连通 → 全量或按水位列增量同步 → 落成与上传同构的数据集），内置 SQLite 示例适配器，企业库位置预留（适配器接口、配置位、端点、mock 测试齐备，接入只需补四个函数），未接入的源界面显示「未接入」，连接串只走环境变量。
- **交互、交付与运维**：React 应用（骨架来自 Vite 模板 + shadcn/ui 组件 + assistant-ui 聊天壳 + 顶部导航栏切页；上传 → 数据集选择 → 对话框 → SQL 折叠 → 结果表 → 结论卡片 → 图表）；流式输出让 SQL、取数行数、结论边生成边显示；步骤面板显示每步用了什么工具、耗时、返回多少行；ECharts 本地资源离线可用、可存 PNG；收藏常用问题一键重跑、任务历史可检索；任一后端故障给可读错误而不白屏。预判耗时 >10s 的分析自动转后台作业（进度可查，服务重启把未完成标 `interrupted`）；导出 Word / PPT / Markdown 报告（结论 + 表格 + 图表截图）与结果集 CSV/Excel。两种形态同源：公网网页端（容器化部署 + 反向代理自动 HTTPS，单密码登录、登录限流、请求频率限制、数据集归属校验）与本地开发/自用（一条命令起服务，或双击 `启动.cmd`）。Windows 桌面端 2026-09-21 已移出范围。
- **质量、可观测与安全**：调用链台账记录每次模型与工具调用的耗时、token、成本（按任务与会话可查、页面有看板）；评测集一条命令跑完 golden set，给出通过率、结论忠实度、降级率、单次成本并与基线对比，不达标即失败；防提示注入（知识库文档、上传文档、MCP 返回内容都视为不可信数据，包裹标记并剥离指令性内容）；SQL 只允许单条 SELECT（拒多语句与建表删改、只读连接、10s 超时、行数封顶）；密钥只从本机配置或环境变量读取，不写进代码、日志、SQL；结论卡片带赞/踩并可一键提升为评测样例，每日 token 与成本配额超额即拒绝新的重分析请求（缓存命中不受影响）；所有阻塞工作（查询、清洗、模型调用、子进程）经统一执行器调度、不阻塞事件循环（默认 4 个线程），单机 4 核下 50 万行聚合 p95 ≤1.5s、缓存命中 p95 ≤100ms、流式首帧 ≤1.2s、10 并发无 5xx 且事件循环心跳 p95 ≤200ms，基线 JSON 存档、退化即验收失败。

## 3. 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 语言 | Python 3.12 | 数据分析生态与打包链最顺 |
| Web 框架 | FastAPI + uvicorn，骨架照官方 `full-stack-fastapi-template` 的目录与依赖注入（借结构不借栈） | 自带 pydantic 校验与 OpenAPI 文档；原生支持 SSE |
| 数据校验 | pydantic v2 + pydantic-settings | HTTP 边界、工具入参、模型结构化输出，以及环境变量与本机配置 |
| 数据处理 | pandas / numpy | 清洗、统计、异常检测与数据画像都是自研（不引 pandera / ydata-profiling，少一层依赖） |
| 分析引擎 | DuckDB（+ duckdb-engine 方言） | 列存聚合快、单文件零部署、可直接查 CSV；SQL 只读与单条 SELECT 由 sqlglot 解析守卫 |
| 元数据存储 | SQLite + SQLAlchemy 2.0 + Alembic | 数据集、任务、会话、缓存、agent 步骤、调用链、评测、作业；建表变更走迁移 |
| 文件解析 | openpyxl / xlrd / Docling / MarkItDown | 表格读写与旧版 xls；PDF 与 Word 先 Docling 后 MarkItDown |
| 报告生成 | docxtpl / python-pptx / Jinja2 | Word 模板、PPT 与 Markdown 报告导出 |
| 模型接入 | LiteLLM | 一个依赖覆盖主流厂商与本地 Ollama，含路由、回退、重试、结构化输出、embedding 与成本 |
| 工具调用 | LangChain `@tool` + LangGraph | 工具声明与 JSON Schema 由框架生成，多步编排走 LangGraph 图；MCP 工具走官方 mcp SDK 并入同一注册表（langchain-mcp-adapters 要求 mcp<2.0，与本仓库的 mcp 2.2 冲突，未装） |
| 会话与记忆 | LangGraph checkpointer（SQLite） | 会话状态持久化，多轮上下文与断点续跑交给框架 |
| 检索与向量 | LlamaIndex + LanceDB | 分块、索引、向量召回与 rerank；关键词 FTS5 保留为降级路径 |
| 缓存 | LiteLLM cache（+ 本地向量） | 精确命中零模型调用；语义命中只复用 SQL、结论重算 |
| 流式协议 | SSE（sse-starlette） | 单向推送足够；客户端断连即取消上游模型调用 |
| 插件协议 | mcp 官方客户端 SDK | 只做客户端，按白名单调用 stdio server |
| 代码沙箱 | RestrictedPython 守卫 + 隔离子进程 | 编译期禁危险调用，进程级隔离（非容器级），超时与输出上限封顶 |
| 观测与成本 | Langfuse（+ 本地 trace 表） | 耗时、token、成本逐次记录；无密钥时只用本地表 |
| 评测 | deepeval + 基线对比 | 结论忠实度与检索质量，低于基线即失败（Ragas 0.4.3 在本机 import 就挂，未装；faithfulness 由 deepeval 同名指标 + 本地确定性口径承担，见 K-047） |
| 前端 | React + Vite + TS + Tailwind + shadcn/ui（TanStack Query / Router、ECharts、assistant-ui 聊天壳 + AI SDK 传输层） | 骨架是 React 模板，组件来自 shadcn/ui；顶部导航栏切页：首页只放导入数据 + 提问 + 结论 + 图表，模型配置与插件各自成页；构建产物静态托管，离线可用 |
| 认证 | itsdangerous + slowapi | 签名 cookie + 限流；单密码校验用 stdlib pbkdf2 |
| 后台作业 | huey（SQLite 后端）+ APScheduler | 长任务转后台、定时同步；单机免 Redis |
| 数据源接入 | dlt + SQLAlchemy | 只读抽数与增量水位；企业库位置留空，驱动按需安装 |
| 并发调度 | 自研固定线程池（`backend/app/core/exec.py`，25 行） | 阻塞调用统一收敛，DuckDB 与 pandas 不卡事件循环（`anyio` 在沙箱子进程路径实测挂住、`run_in_threadpool` 是 async 口子而调用点全是同步函数，都没有可用对应物，见 K-044） |
| 反向代理 / 容器 | Caddy / Docker（多阶段：node 构建前端 → python 运行时）+ docker-compose | HTTPS 一条命令，容器化部署 |
| 质量工具 | pytest + ruff | 每阶段一个测试文件 |
| 性能验证 | bench 脚本 + 基线 JSON | 性能退化即验收失败 |

## 4. 明确不做

模型微调/LoRA/蒸馏/自训练；K8s、多租户 RBAC、合规审计体系；自建推理集群（本地模型走 Ollama）；自研向量检索引擎、embedding、AI 网关与计费；扫描件 OCR、移动端适配；对企业库的写入与 DDL；自研 ETL 调度平台。

## 5. 容量与性能预期

定位单人或小团队、单机部署：单文件 50MB，结果集 5000 行封顶（超出截断并提示），知识库召回 20 取 5，SQL 超时 10s，代码沙箱 20s，模型与插件各自独立超时，单次分析默认 ≤6 步，默认每日成本配额 5 美元（超出拒绝重分析，缓存命中不受限）。

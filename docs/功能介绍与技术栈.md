# AI 数据分析助手 · 功能介绍与技术栈

面向使用者与评审，不含施工细节；**本文写的是目标形态**，已实现范围（MVP 七段）看 `最小可用集.md`。契约与阶段计划见 `系统总体设计.md`，当前进度与已知问题见 `代码台账.md`，第一版（MVP）范围见 `最小可用集.md`。

## 1. 一句话定位

上传表格和文档，用中文多轮提问，模型自己规划步骤、调用工具查数与算数，最后给出带数字依据的结论、图表和可导出的报告；Skill、知识库、MCP 插件、模型都可替换，部署形态可以是公网网页，也可以是 Windows 桌面安装包。

## 2. 功能清单

- **数据接入与清洗**：CSV/XLSX/XLS（≤50MB，多 sheet 取首个并记进清洗日志）；PDF/Word 走知识库通道（扫描件 OCR 不做）；自动清洗（列名归一、类型推断、完全重复行去重、缺失率统计、空列提示）+ 数据画像（行列数、字段类型、缺失率、枚举样例）；数据集带版本号（重导入或改清洗规则 +1，问答缓存同步失效）与 schema drift 报告。
- **分析、结论与口径**：模型自主规划多步工具调用（默认 ≤6 步、每步轨迹可查），工具含 SQL、描述统计、异常检测、知识库检索、技能、MCP、受限代码执行、指标口径、报告导出；多跳问题一次问完；每步取数与 `/query` 同口径（≤5000 行），回给模型的超限结果只回摘要与列名；步数用尽返回已完成步骤而不报错。统计含描述统计（计数、去重计数、分位数、均值方差）与 IQR + z-score 双规则异常（标出依据）；结论结构化输出（摘要/发现/异常/建议/置信度/注意事项）且数字可回溯，证据不足写进注意事项而不编造，指代不清先反问；指标语义层集中定义口径（别名、公式、单位、归属人），未定义的指标不臆造公式。表达不了的分析可写 pandas 代码（自定义指标、复杂分箱、时间序列）：独立子进程、临时目录、20s 超时、输出 ≤1MB、import 白名单、只注入当前数据集只读副本——进程级隔离而非容器级，公网多租户需换容器方案。
- **多轮对话与问答复用**：会话内追问支持指代式提问（带最近 6 轮提问与 SQL、最近 2 轮结论摘要）；相同问题命中精确缓存（毫秒级、零模型调用、零成本），同义改写命中语义缓存（复用历史 SQL、结论按当前数据重算）；缓存按「数据集 + 数据版本 + 模型 + 提示词版本」隔离；命中率分精确与语义两栏可查。
- **可扩展与外部接入**：**Skill**（目录技能包 `SKILL.md` + 可选脚本，prompt 型注入上下文、script 型受限子进程执行、可单独启停）；**知识库**（md/txt/pdf/docx，向量召回 20 取 5、答案带出处、embedding 不可用时回退关键词检索）；**MCP 插件**（按配置接标准 server、自动发现工具、白名单调用、崩溃或超时只降级该能力）——三者都可一键关闭。**模型接入**覆盖 OpenAI、DeepSeek、通义千问、Kimi、智谱、Gemini 兼容端点、本地 Ollama；新增厂商通常只改一份 JSON 配置，P5 起也能在页面填 base_url + 模型名 + 密钥（写本机 `config/local.json`，免重启）；按用途分配模型（生成 SQL 用便宜小模型、写结论用强模型）；失败按回退链换备选，全挂给结构化说明；未配密钥的模型界面标不可用。**多表关系**：自动推断关联列（列名同义 + 类型一致 + 值交集采样）并给置信度与候选，确认后才允许 join，未登记的跨表 join 被拒并回传候选。**企业数据库**：只读拉取（配数据源 → 测连通 → 全量或按水位列增量同步 → 落成与上传同构的数据集），内置 SQLite 示例适配器，企业库位置预留（适配器接口、配置位、端点、mock 测试齐备，接入只需补四个函数），未接入的源界面显示「未接入」，连接串只走环境变量。
- **交互、交付与运维**：单页前端（上传 → 数据集选择 → 对话框 → SQL 折叠 → 结果表 → 结论卡片 → 图表）；流式输出让 SQL、取数行数、结论边生成边显示；步骤面板显示每步用了什么工具、耗时、返回多少行；ECharts 本地资源离线可用、可存 PNG；收藏常用问题一键重跑、任务历史可检索；任一后端故障给可读错误而不白屏。预判耗时 >10s 的分析自动转后台作业（进度可查，服务重启把未完成标 `interrupted`）；导出 Word / PPT / Markdown 报告（结论 + 表格 + 图表截图）与结果集 CSV/Excel。三种形态同源：公网网页端（容器化部署 + 反向代理自动 HTTPS，单密码登录、登录限流、请求频率限制、数据集归属校验）、Windows 桌面版（`Knowledge-Analysis-Assistant-Setup.exe` 一键安装、双击启动自动打开界面、数据在 `%APPDATA%`、密钥由首启向导填写、程序内不含任何密钥）、本地开发（一条命令起服务，或双击 `启动.cmd`）。
- **质量、可观测与安全**：调用链台账记录每次模型与工具调用的耗时、token、成本（按任务与会话可查、页面有看板）；评测集一条命令跑完 golden set，给出通过率、结论忠实度、降级率、单次成本并与基线对比，不达标即失败；防提示注入（知识库文档、上传文档、MCP 返回内容都视为不可信数据，包裹标记并剥离指令性内容）；SQL 只允许单条 SELECT（拒多语句与建表删改、只读连接、10s 超时、行数封顶）；密钥只从本机配置或环境变量读取，不写进代码、日志、SQL；结论卡片带赞/踩并可一键提升为评测样例，每日 token 与成本配额超额即拒绝新的重分析请求（缓存命中不受影响）；所有阻塞工作（查询、清洗、模型调用、子进程）经统一执行器调度、不阻塞事件循环（默认 4 个线程），单机 4 核下 50 万行聚合 p95 ≤1.5s、缓存命中 p95 ≤100ms、流式首帧 ≤1.2s、10 并发无 5xx 且事件循环心跳 p95 ≤200ms，基线 JSON 存档、退化即验收失败。

## 3. 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 语言 | Python 3.11+ | 数据分析生态与打包链最顺 |
| Web 框架 | FastAPI + uvicorn | 自带 pydantic 校验与 OpenAPI 文档；原生支持 SSE |
| 数据校验 | pydantic v2 | 同时管 HTTP 边界、工具入参与大模型结构化输出 |
| 数据处理 | pandas / numpy | 清洗、统计、异常检测；向量暴力检索 |
| 分析引擎 | DuckDB | 列存聚合快、单文件零部署、可直接查 CSV，承载数据集表与 FTS5 |
| 元数据存储 | SQLite | 数据集、任务、会话、缓存向量、agent 步骤、调用链、评测、作业 |
| 文件解析 | openpyxl / xlrd / pypdf / python-docx | 表格读写、旧版 xls、PDF 与 Word 文本抽取 |
| 报告生成 | python-docx / python-pptx | Word 与 PPT 报告导出 |
| 模型接入 | openai + anthropic SDK | 两个适配器覆盖主流厂商，含 embedding |
| 工具调用 | 模型原生 function calling | 自建工具注册表 + JSON Schema，不引 agent 框架 |
| 流式协议 | SSE（Server-Sent Events） | 单向推送足够，FastAPI 原生支持 |
| 插件协议 | mcp 官方客户端 SDK | 只做客户端，按白名单调用 stdio server |
| 代码沙箱 | 隔离子进程 + 超时 + import 白名单 | 进程级隔离，非容器级 |
| 向量检索 | numpy 暴力余弦 + 模型重排 | 十万级数据免引向量数据库 |
| 评测 | pytest 驱动 JSONL golden set + 基线对比 | 结果进 git，防 prompt 退化 |
| 可观测 | 自建 trace 表 + 看板页 | 免引 Langfuse 一类外部服务 |
| 前端 | 原生 HTML/JS + ECharts（本地 `web/vendor/`） | 单页够用，不引框架与构建链，离线可用 |
| 认证 | stdlib hmac + hashlib | 单密码哈希 + 签名 cookie |
| 反向代理 / 容器 | Caddy / Docker | HTTPS 一条命令，容器化部署 |
| 桌面打包 | PyInstaller onedir + Inno Setup | 生成 Windows 安装包；不做 onefile |
| 质量工具 | pytest + ruff | 每阶段一个测试文件 |
| 并发调度 | 自建 run_blocking 线程池执行器 | 统一收敛阻塞调用，DuckDB 与 pandas 不卡事件循环 |
| 数据源接入 | 适配器接口 + SQLite 示例实现 | 企业库位置留空，接口齐备、驱动按需安装 |
| 性能验证 | bench 脚本 + 基线 JSON | 性能退化即验收失败 |

## 4. 明确不做

模型微调/LoRA/蒸馏/自训练；K8s、多租户 RBAC、合规审计体系；自建推理集群（本地模型走 Ollama）；自研向量检索引擎、embedding、AI 网关与计费；扫描件 OCR、移动端适配、桌面端自动更新与代码签名；对企业库的写入与 DDL；自研 ETL 调度平台。

## 5. 容量与性能预期

定位单人或小团队、单机部署：单文件 50MB，结果集 5000 行封顶（超出截断并提示），知识库召回 20 取 5，SQL 超时 10s，代码沙箱 20s，模型与插件各自独立超时，桌面安装包 200–350MB，单次分析默认 ≤6 步，默认每日成本配额 5 美元（超出拒绝重分析，缓存命中不受限）。

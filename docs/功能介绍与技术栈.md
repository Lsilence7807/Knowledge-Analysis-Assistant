# AI 数据分析助手 · 功能介绍与技术栈 v1.2

配套文档：`系统总体设计.md`（契约、阶段计划、验收命令）。本文件面向使用者与评审者，不含施工细节。

## 1. 一句话定位

上传表格和文档，用中文多轮提问，模型自己规划步骤、调用工具去查数和算数，最后给出带数字依据的结论、图表和可导出的报告；Skill、知识库、MCP 插件、模型都可替换，部署形态可以是公网网页也可以是 Windows 桌面安装包。

## 2. 功能清单

### 2.1 数据接入与清洗

- 格式：CSV、XLSX、XLS；文档类 PDF、Word 走知识库通道（扫描件 OCR 不做）
- 单文件上限默认 50MB；多 sheet 取首个并在清洗日志注明
- 自动清洗：列名归一、类型推断、完全重复行去重、缺失率统计、空列提示
- 清洗规则参数（缺失阈值、去重键、异常倍数）集中可调
- 每次导入生成数据画像：行列数、字段类型、缺失率、枚举值样例
- 数据集带版本号；重导入或改规则即版本 +1，历史问答缓存同步失效
- 重导入时输出 schema drift 报告：字段增删与类型变更逐条列出

### 2.2 多步分析与工具调用

- 模型自主规划：先查什么、再下钻什么，默认最多 6 步，每步轨迹可查
- 可调用工具：执行 SQL、描述统计、异常检测、知识库检索、技能、MCP 工具、受限代码执行、指标口径、报告导出
- 多跳问题一次问完：「先找环比下降最多的产品，再按渠道拆开」不用连着问三轮
- 每步结果超限只回传摘要与列名，避免上下文被大表撑爆
- 步数用尽时返回已完成步骤与阶段性结论，不报错
- 工具白名单可配；写类工具默认关闭

### 2.3 统计、洞察与口径

- 描述统计：计数、去重计数、分位数、均值方差
- 异常识别：IQR 与 z-score 双规则，标出异常行与判定依据
- 趋势与结构：同比、环比、移动平均、分组聚合与占比
- 结论结构化输出：摘要 / 发现 / 异常 / 建议 / 置信度 / 注意事项，数字可回溯到结果表
- 证据不足写进注意事项，不编造；指代不清先反问
- 指标语义层：销售额、环比等口径集中定义（含别名、公式、单位、归属人），模型必须按定义算，没定义的指标不会自己编公式

### 2.4 多轮对话与问答复用

- 会话内多轮追问，支持指代式提问（「那再按区域拆一下」），上下文带最近 6 轮提问与 SQL、最近 2 轮结论摘要
- 相同问题命中精确缓存：直接返回历史答案，不调用模型，毫秒级且零成本
- 问法相近（同义改写）：语义缓存命中，复用历史 SQL 重新执行，结论按当前数据重算
- 缓存按「数据集 + 数据版本 + 模型 + 提示词版本」隔离，数据变了旧结论自动作废
- 命中率可查，精确与语义分列统计

### 2.5 受限代码执行

- 表达不了的分析可以写 pandas 代码执行（自定义指标、复杂分箱、时间序列处理）
- 隔离运行：独立子进程、临时目录、20 秒超时、输出上限 1MB、仅放行白名单模块、只注入当前数据集的只读副本
- 明确边界：进程级隔离，不是容器级；面向公网多租户需换容器方案

### 2.6 可扩展能力

- **Skill 导入**：目录形式技能包（`SKILL.md` + 可选脚本），提示词型注入上下文，脚本型在受限子进程执行，可单独启停
- **知识库**：md/txt/pdf/docx 导入；向量召回 + 模型重排取前 5，答案带出处；embedding 不可用时回退关键词检索
- **MCP 插件**：按配置接入标准 MCP server，自动发现工具，白名单调用；插件崩溃或超时只降级该能力
- 三者均可一键关闭，便于排查与降低外部依赖

### 2.7 模型接入

- 覆盖 OpenAI、DeepSeek、通义千问、Kimi、智谱、Gemini 兼容端点、本地 Ollama
- 新增厂商通常只改一份 JSON 配置
- 按用途分配模型：生成 SQL 用快而便宜的小模型，写结论用强模型
- 失败回退链：主模型不可用自动试备选，全挂返回结构化说明而非报错
- 每个请求可指定模型；未配密钥的模型在界面标为不可用

### 2.8 前端与交互

- 单页：上传 → 数据集选择 → 对话框 → SQL 折叠 → 结果表 → 结论卡片 → 图表
- 流式输出：SQL、取数行数、结论边生成边显示，首字即出，不用干等
- 步骤面板：能看到模型每一步调了什么工具、耗时、返回多少行
- 图表前端渲染（ECharts），可存 PNG
- 收藏常用问题一键重跑；任务历史可检索
- 降级可见：模型或插件不可用时给出提示，已算出的表格照常展示

### 2.9 长任务与后台作业

- 预计超过 10 秒的分析自动转后台，界面显示进度，可继续做别的事
- 作业进度可轮询或订阅；服务重启后未完成作业标记为中断，不留假运行状态

### 2.10 报告与导出

- 结果表导出 CSV / Excel
- 一键导出分析报告：Word、PPT、Markdown（含结论、表格、图表截图、SQL 与数据版本）

### 2.11 部署与交付形态

- **公网网页端**：容器化部署，反向代理自动签发 HTTPS，单密码登录、登录限流、请求频率限制、数据集归属校验
- **Windows 桌面版**：一键安装的 `DataCopilot-Setup.exe`，双击启动自动打开界面，数据存本机 `%APPDATA%`，模型密钥由使用者在首启向导填写，程序内不含任何密钥
- 本地开发模式：一条命令起服务，无需打包

### 2.12 质量、可观测与安全

- 调用链台账：每次模型与工具调用的耗时、token、成本落库，可按任务与会话查询，页面有成本与耗时看板
- 评测集：内置 golden set（问题、期望列、期望结论字段、禁用措辞），一条命令跑完并给出通过率、结论忠实度、降级率、单次成本，与基线对比，不达标直接失败
- 防提示注入：知识库文档、上传文档、MCP 返回内容都视为不可信数据，包裹标记并剥离指令，文档内容无法触发工具调用或数据导出
- SQL 只允许单条 SELECT，拒多语句与建表删改，只读连接、10 秒超时、结果行数封顶
- 密钥只从环境变量或本机配置读取，不写入代码、日志、SQL；日志不记文件内容与完整提示词
- 任一外部能力故障均为局部降级，接口仍正常返回

### 2.13 多表分析与关系

- 多张表自动推断关联列：列名同义 + 类型一致 + 值交集采样，给出置信度与候选清单
- 关系确认后才允许 join；未登记关系的跨表 join 会被拒绝并回传候选，避免模型乱猜关联条件
- 关系可手动登记与撤销，随数据集版本管理

### 2.14 对接企业数据库

- 从数据库只读拉取：配置数据源（连接串只走环境变量）→ 测试连通性 → 全量或按水位列增量同步 → 落成与上传文件同构的数据集
- 已内置 SQLite 示例适配器；**企业库位置预留**——适配器接口、配置位、接口端点、mock 测试齐备，接入具体厂商时只需补四个函数（连接、列库表、读表、方言），主链路一行不改
- 未接入的企业源在界面显示「未接入」，不影响其他功能
- 只读拉取，永不写库；同步后的数据集同样有版本号、画像与字段变更报告

### 2.15 反馈闭环与成本控制

- 结论卡片带赞/踩；点踩可填原因或修正 SQL，落库留痕
- 一键把一条踩提升为评测样例，自动追加进 golden set，下次评测即生效——这是系统持续变好的唯一通道
- 每日成本与 token 配额：超额后拒绝新的重分析请求并给出说明，缓存命中不受影响
- 用量看板：当日消耗、剩余额度、按任务维度的成本明细

### 2.16 性能与并发目标

- 并发模型：所有阻塞工作（查询、清洗、模型调用、子进程）统一经执行器调度，不阻塞事件循环；默认 4 个工作线程
- 单机 4 核目标：50 万行聚合 p95 ≤ 1.5 秒；缓存命中 p95 ≤ 100 毫秒；流式首帧 ≤ 1.2 秒；10 并发无 5xx 且心跳延迟 p95 ≤ 200 毫秒
- 基线以 JSON 存档，退化即验收失败

## 3. 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 语言 | Python 3.11+ | 数据分析生态与打包链最顺 |
| Web 框架 | FastAPI + uvicorn | 自带 pydantic 校验与 OpenAPI 文档；原生支持 SSE |
| 数据校验 | pydantic v2 | 同时管 HTTP 边界、工具入参与大模型结构化输出 |
| 数据处理 | pandas / numpy | 清洗、统计、异常检测；向量暴力检索 |
| 分析引擎 | DuckDB | 列存聚合快、单文件零部署、可直接查 CSV，承载数据集表与 FTS5 |
| 元数据存储 | SQLite | 数据集、任务、会话、缓存向量、agent 步骤、调用链、评测、作业 |
| 文件解析 | openpyxl / pypdf / python-docx | 表格读写、PDF 与 Word 文本抽取 |
| 报告生成 | python-docx / python-pptx | Word 与 PPT 报告导出 |
| 模型接入 | openai + anthropic SDK | 两个适配器覆盖主流厂商，含 embedding |
| 工具调用 | 模型原生 function calling | 自建工具注册表 + JSON Schema，不引 agent 框架 |
| 流式协议 | SSE（Server-Sent Events） | 单向推送足够，FastAPI 原生支持 |
| 插件协议 | mcp 官方客户端 SDK | 只做客户端，按白名单调用 stdio server |
| 代码沙箱 | 隔离子进程 + 超时 + import 白名单 | 进程级隔离，非容器级 |
| 向量检索 | numpy 暴力余弦 + 模型重排 | 十万级数据免引向量数据库 |
| 评测 | pytest 驱动 JSONL golden set + 基线对比 | 结果进 git，防 prompt 退化 |
| 可观测 | 自建 trace 表 + 看板页 | 免引 Langfuse 一类外部服务 |
| 前端 | 原生 HTML/JS + ECharts（本地 `web/vendor/`，离线可用） | 单页够用，不引框架与构建链 |
| 认证 | stdlib hmac + hashlib | 单密码哈希 + 签名 cookie |
| 反向代理 / 容器 | Caddy / Docker | HTTPS 一条命令，容器化部署 |
| 桌面打包 | PyInstaller onedir + Inno Setup | 生成 Windows 安装包；不做 onefile |
| 质量工具 | pytest + ruff | 每阶段一个测试文件 |
| 并发调度 | 自建 run_blocking 线程池执行器 | 统一收敛阻塞调用，DuckDB 与 pandas 不卡事件循环 |
| 数据源接入 | 适配器接口 + SQLite 示例实现 | 企业库位置留空，接口齐备、驱动按需安装 |
| 性能验证 | bench 脚本 + 基线 JSON | 性能退化即验收失败 |

## 4. 明确不做

- 模型微调、LoRA、蒸馏、自训练模型
- K8s、多租户 RBAC、合规审计体系
- 自建推理集群（vLLM、量化部署）；本地模型走 Ollama
- 自研向量检索引擎、自研 embedding、自研 AI 网关与计费
- 扫描件 OCR、移动端适配、桌面端自动更新与代码签名
- 对企业库的写入与 DDL（数据源一律只读拉取）
- 自研 ETL 调度平台

## 5. 容量与性能预期

- 定位：单人或小团队，单机部署
- 单文件 50MB；结果集 5000 行封顶（超出截断并提示）；知识库检索召回 20 取 5
- SQL 超时 10 秒；代码沙箱 20 秒；模型与插件各自独立超时
- 精确缓存命中毫秒级且零模型费用；语义缓存命中只产生一次执行成本
- 桌面安装包预期 200–350MB；单次分析默认步数上限 6
- 并发与延迟目标见 2.16 节；默认每日成本配额 5 美元，超出拒绝重分析（缓存命中不受限）

# AI 数据分析助手 · 最小可用集功能说明

配套文档：`最小可用集-系统设计.md`（契约与 7 段施工计划）。全量能力见 `功能介绍与技术栈.md`，本文件只描述第一版能做什么。

## 1. 一句话

上传一张业务表格，用中文提问，模型自己规划几步、依次调用查询与统计工具，最后给出结果表、结论和建议，网页上直接看。

## 2. 能做什么

**数据接入**
- 上传 CSV / XLSX / XLS，单文件默认上限 50MB，多 sheet 取第一个并在清洗日志里注明
- 自动清洗：列名归一、类型推断、完全重复行去重、缺失率统计
- 生成数据画像：行列数、字段类型、缺失率、枚举值样例
- 数据集列表与画像随时可查

**查询与统计**
- 手写 SQL 查询（只允许单条 SELECT；多语句、建表删表改数据一律拒绝；只读连接、10 秒超时、5000 行封顶）
- 描述统计：计数、去重计数、分位数、均值方差
- 异常识别：IQR 与 z-score 双规则，标出异常行与判定依据

**提问与多步分析**
- 中文提问，模型自主规划步骤，默认最多 6 步，每步调用了什么工具、耗时、返回多少行都能看到
- 可调用的工具：执行 SQL、描述统计、异常检测
- 多跳问题一次问完：「先找环比下降最多的产品，再按渠道拆开」不用分两轮
- 每步结果超过 200 行只回传摘要与列名，避免大表撑爆上下文
- 步数用尽时返回已完成步骤和阶段性结论，不报错
- 模型不可用时降级：返回可读说明，已经算出来的结果表照常展示

**结论输出**
- 结构化结论：摘要 / 发现 / 异常 / 建议 / 置信度 / 注意事项
- 结论里的数字都能在结果表中找到；证据不足会写进注意事项，不编造
- 指代不清的问题会先反问，不猜

**前端**
- 单页：上传 → 选数据集 → 提问 → SQL 折叠查看 → 结果表 → 步骤面板 → 结论卡片 → ECharts 图表
- SQL 与结果都是可选中的纯文本（页面不提供复制按钮），方便复制出来核对模型有没有理解错

## 4. 技术栈（MVP）

| 层 | 选型 | 说明 |
|---|---|---|
| 语言 | Python 3.11+ | |
| Web | FastAPI + uvicorn | 自带校验与 OpenAPI 文档 |
| 校验 | pydantic v2 | HTTP 边界与模型输出 |
| 数据处理 | pandas | 清洗与统计 |
| 分析引擎 | DuckDB | 列存聚合、单文件零部署 |
| 元数据 | SQLite | 数据集、任务、步骤、能力日志 |
| 模型接入 | openai SDK（OpenAI 兼容） | 换 DeepSeek/Qwen 只改 config |
| 工具调用 | 模型原生 function calling | 自建注册表，不引 agent 框架 |
| 前端 | 原生 HTML/JS + ECharts（本地 `web/vendor/`，离线可用） | 单页，无构建链 |
| 测试 | pytest + ruff | 每阶段一个测试文件 |

后引入：python-docx / python-pptx / pypdf（P19）、mcp（P8）、anthropic（P9）、pyinstaller（P12）、numpy（P14）。认证(P11) 用标准库，不引第三方。

## 5. 运行与配置

```
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
# 页面就在 http://127.0.0.1:8000/（接口文档在 /docs）
# 模型接入：在页面上配任意 OpenAI 兼容厂商（base_url + 模型名 + 密钥，P5 起），或写 config/local.json；环境变量只是兜底
```

| 环境变量 | 默认 | 说明 |
|---|---|---|
| LLM_API_KEY | 无 | 最兜底的密钥来源（优先用页面写入的 `config/local.json`，其次该 profile 声明的 `api_key_env`）；都没有时提问降级为「只能手写 SQL」，其余功能照常 |
| DATA_DIR | ./data | duckdb、sqlite、上传文件 |
| MAX_UPLOAD_MB | 50 | 上传上限 |
| ENABLE_AGENT | true | false 时走单跳路径（不做多步） |
| AGENT_MAX_STEPS | 6 | 步数预算 |

模型改哪家：在页面上配（P5 起，写 `config/local.json`），或直接改 `config/models.json`；工具白名单与超时看 `config/tools.json`。

## 维护规则

- 每段验收通过后更新一次，由 AGENT 负责，只增不删。
- 状态取值：已完成 / 待修改 / 已修复。
- 「已知问题」写清现象、触发条件、所在函数、是否已修；修好后改状态并保留原行。

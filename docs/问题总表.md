## 1. 还没关的（10 条）

### 1.1 要人拍板 / 要装东西（4 条）

**K-052 评测 fidelity 达不到基线（要人拍板）**
- 现象：真机 `POST /evals/run` 得 `sql_pass_rate=1.0 / fidelity_rate=0.6667`（换配置下 0.3333），`evals/baseline.json` 基线写 0.95 → `baseline_delta=-0.2833`，`python -m app.evalharness` 按口径 exit 1。
- 为什么不算 bug：q001 的结论数字没在结果表出现、q003 用 top-5 明细答「平均值」，是模型真答偏，不是断言写错。
- 怎么关（三选一）：① 按真机实测重定基线并在 `docs/系统总体设计.md` §4.10 登记；② 先定 faithfulness 口径（deepeval 的 `deepeval_faithfulness` 还是本地 `insight.unsupported_numbers`）；③ 这条只当告警、不卡退出码。

**K-053 登出不失效（要人拍板）**
- 现象：`POST /logout` 只清客户端 cookie。签名 cookie 自包含、服务端没有会话表，被复制走的旧 cookie 在有效期内照样过认证；只有改 `APP_PASSWORD_HASH` 才让全部旧 cookie 失效。
- 位置：`backend/app/core/security.py`（`_secret` / `logout`）、`backend/app/api/routes/auth.py`。
- 怎么关（二选一）：① 接受无状态（登出 = 清 cookie），把这条口径写进设计文档 §4.3/§4.4；② 加服务端失效（cookie 带口令版本或 jti + 撤销表，约十几行）。

**K-048 镜像与 compose 没在真机跑过（要人装 Docker）**
- 现象：本机没装 Docker Desktop，`deploy/Dockerfile`、`deploy/Caddyfile`、`docker-compose.yml` 只做了静态校验（YAML 能解析、服务名/卷/COPY 源/`package-lock.json` 引用都在），没跑过 `docker compose up --build`。
- 怎么关：装 Docker 后 `docker compose up --build` → `curl http://127.0.0.1:8017/health` → 走一次 SSE；`FRAMEWORK_PROFILE=full` 那档同理（要下 GB 级依赖）。细则见 `docs/留白-未测项.md` 第 1 节。

**K-041 响应模型没补全（待定）**
- 现象：§5 的 F1 要求「每个路由挂响应模型（OpenAPI 完整）」，实际只有改造前就有的 HealthOut / CapabilitiesOut，其余端点仍是 `-> dict`，所以 `/openapi.json` 里多是 `additionalProperties`。
- 为什么搁置：补 response_model 会让 FastAPI 按模型过滤响应载荷，和「F 段不动响应载荷」冲突，风险大于收益；建议维持现状，只在前端真正用到的端点补，改载荷要回设计文档登记。

### 3.2 本机（Windows + PowerShell）施工坑

- 本会话里 `apply_patch` 工具**不可用**：改已有文件用「写临时 `.py` 脚本 → `& .\.venv\Scripts\python.exe <脚本>`」，脚本里 `read_text("utf-8")` → `assert count == 1` → `replace` → `write_text(..., newline="\n")`。新建文件可以直接 `Set-Content`。
- PowerShell 里**不要**内联多行 Python 字符串：引号会被 PS 吃掉，报 `SyntaxError` / `ParserError`。一律先 `Set-Content` 落到 `.py` 再跑。
- `Set-Content -Encoding utf8` 会带 BOM：事后用 python `p.write_text(p.read_text("utf-8-sig"), encoding="utf-8", newline="\n")` 去掉。
- PowerShell **没有 `head`**；`gh run list --json` 的字段名不能随便加（`headSha` 不在可选字段里）；要看 CI 直接 `gh run list -L 3` 的表格输出。
- python 往控制台打中文会乱码（控制台编码）：要看中文内容就在脚本里 `.encode("unicode_escape").decode("ascii")` 再打。
- `Remove-Item -Recurse` 被本机策略拦住：`%TEMP%\kaa-core`（空 venv，约 400MB）删不掉，需要人工删。
- 端口约定：`启动.cmd` 固定 **8017**；测试与探针用 **8018+**（浏览器套件默认 8018）。起长任务用会话轮询，别小间隔反复查。

### 3.3 跑测试的注意事项

- 全量：`& .\.venv\Scripts\python.exe -m pytest tests -q -p no:warnings`（约 2.5 分钟）。
- 浏览器套件默认**整模块跳过**：`$env:KAA_E2E="1"` 才跑（约 36 秒），所以 **CI 绿不代表浏览器测过**。
- 没装 `pytest-timeout`，别加 `--timeout=`。
- 加了新依赖：当轮重生成 `requirements.lock`，并跑 `pip check` + `tests/test_p8_mcp.py`（K-045 / K-050 就是这么踩的）。
- 跑完记得看 `git status`：`data/`、`config/local.json` 都该是 gitignore 挡住的。

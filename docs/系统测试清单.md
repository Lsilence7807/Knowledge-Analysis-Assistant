# 全量系统 · 测试清单（25 个阶段）

配套：`系统总体设计.md`。设计文档给每段一条验收命令；本文件回答「怎么算测全了」——逐段成功用例、反例用例、手工项，外加 12 项跨阶段专项测试与一套完成定义。

命令约定：项目根目录执行，用项目虚拟环境：

```
& .\.venv\Scripts\python.exe -m pytest tests/test_p22_relations.py -q
```

静态质量门（每个阶段提交前和验收命令一起跑，配置在 `pyproject.toml`）：

```
& .\.venv\Scripts\python.exe -m ruff check app tests
& .\.venv\Scripts\python.exe -m ruff format --check app tests
```

## 0. 三层 + 一项

| 层 | 含义 | 通不过怎么办 |
|---|---|---|
| 自动（成功） | 正常输入的预期行为 | 改代码 |
| 反例（负向） | 必须被拒绝、降级或中断的输入 | 改代码；漏一条算没完 |
| 手工 | 浏览器、真实模型、真实设备上的人工确认 | 记现象，能修就修，修不了记台账 |
| 专项 | 跨阶段的攻击面与正确性专题（第 3 节） | 每个上线节点前必须全过 |

## 2. 逐段测试项

### P0 骨架

- 自动：`/health` 200；`/capabilities` 返回全部能力键；`ensure_tables()` 幂等；配置默认值正确
- 反例：未知路径 404；未实现端点返回 404/405 而不是 500；provider 缺失时 `/capabilities` 不崩
- 手工：启动无 traceback

### P1 摄取

- 自动：清洗后列名归一、类型推断、去重、缺失率与画像一致；`table_version=1`；GBK 可读；多 sheet 取首个并记 log
- 反例：`.exe` 被拒；超限 413；空文件被拒且不留半个数据集；公式列 xlsx 不崩；不存在 id 404
- 手工：网页显示数据集与画像

### P2 查询与统计

- 自动：聚合查询行数正确；`/stats` 返回描述统计与异常依据
- 反例：DDL/DML、多语句、注释绕过、尾分号、写 CTE、查不存在表、超 5000 行截断、长查询超时
- 手工：手写 SQL 出表

### P3 提问转 SQL

- 自动：固定问题出非空结果表；返回结构含 `degraded`
- 反例：无密钥降级；mock 返回 DROP 被拦；mock 返回非法 JSON 重试后降级；超长输出被截断
- 手工：真实 Key 下 3 个业务问题

### P4 洞察生成

- 自动：字段齐全；数字可回溯；`prior=[]` 不报错
- 反例：缺字段降级；编造数字被校验识别；模型全挂时仍返回结果表
- 手工：结论与表格对得上

### P5 前端闭环

- 自动：首页 200；全链路上传→ask→insight 非空；`GET /settings/models` 不回传密钥明文，`PUT` 新增一个自定义厂商 profile 后 `/ask` 走该 profile 不再降级（模型调用用替身，不真出网）
- 反例：后端 500 时页面显示可读错误不白屏
- 手工：脏 CSV、多跳提问、图表切换、SQL 折叠、断网降级提示、无控制台报错；页面填任意厂商地址与密钥后提问出结果表，刷新后配置仍在

### P6 Skill 导入与执行

- 自动：导入目录并解析 frontmatter；列表正确；prompt 型片段进入上下文；script 型子进程执行返回
- 反例：路径逃逸 `../../` 被拒；script 超时被杀；未声明入口不可执行；SKILL.md 缺 frontmatter 被拒
- 手工：禁用某 skill 后其片段不再出现

### P7 知识库（关键词）

- 自动：导入分块；FTS 命中且带出处
- 反例：二进制文件被拒；重复导入不产生重复块；单块不超上限
- 手工：检索结果与问题相关

### P8 MCP 插件

- 自动：列出工具；调用白名单只读工具成功
- 反例：server 启动失败 → `capabilities.mcp=false` 且 500 不出现；调用超时降级；白名单外工具被拒；kill server 后进程被回收
- 手工：`/mcp/tools` 显示的是配置里那台 server 的工具

### P9 多模型接入

- 自动：两个适配器都能出结构化结果；逐次指定 `model_id` 生效
- 反例：主模型 500 → 自动 fallback；fallback 链全挂 → 降级 200；未配密钥的模型标 unavailable；非法 JSON 重试后降级
- 手工：`/models` 与实际可用性一致

### P10 会话记忆与精确缓存

- 自动：指代型追问可解；命中 `cached=true` 且零模型调用；`table_version` 变化后不命中
- 反例：换数据集 / 换模型 / 改 PROMPT_VERSION 都不命中；缓存里查不到文件内容；不存在的 session 返回可读错误
- 手工：第二轮追问明显更快

### P11 公开网页端

- 自动：正确密码拿到 cookie；401 / 413 / 429 行为正确
- 反例：错误密码、无 cookie、他人数据集、超大上传、超频请求、篡改 cookie（签名校验失败）
- 手工：`AUTH_DISABLED=false` 下本地也要求登录

### P12 桌面 exe

- 自动：数据目录解析、首启向导写入、配置读取
- 反例：无密钥启动给引导不崩；端口占用能换端口；数据目录只读给可读错误
- 手工：干净 Windows 安装、离线跑通全链路（图表走本地资源）、`%APPDATA%` 里能看到数据

### P13 Agent 循环与工具调用

- 自动：多跳两步入内完成；单跳退化为 1 步；步数耗尽返回已完成步骤；`agent_steps` 条数与 `steps` 一致
- 反例：白名单外工具被拒并留痕；不存在的工具名不崩；工具抛异常不导致 500；单步超 200 行回模型的只给摘要（响应结果表仍按 5000 行口径）
- 手工：步骤面板与落库一致

### P14 语义检索与语义缓存

- 自动：同义问法 `reused_sql=true` 且 insight 重算；向量召回 + 重排
- 反例：阈值边界（0.92 不命中 / 0.94 命中）；无关问题不误命中；embedding 不可用回退 FTS；rerank 返回非法 JSON 用原始顺序
- 手工：知识库命中片段确实相关

### P15 沙箱与指标语义层

- 自动：自定义指标计算成功；指标别名解析正确
- 反例：`import os`、写文件、联网、死循环、巨量输出、内存爆炸；未定义指标被标注而非臆造公式
- 手工：`/metrics/definitions` 与配置一致

### P16 评测、可观测与安全加固

- 自动：trace 落表、成本聚合、golden 运行、基线对比
- 反例：低于基线 exit 1；注入样本不改变行为；trace 不记录 prompt 全文与文件内容
- 手工：`/trace/stats` 能回答「这周花了多少钱、慢在哪」

### P17 流式输出

- 自动：帧序正确、`done` 唯一、`sql` 早于 `token`
- 反例：客户端断开 → 模型调用被取消且记 `canceled`；慢客户端不拖垮其他请求
- 手工：首帧延迟可感

### P18 后台作业

- 自动：提交返回 `job_id`、进度到 done、结果可取
- 反例：重复提交同一作业；重启后未完成标 `interrupted`；不存在 `job_id` 404
- 手工：长任务期间界面可继续操作

### P19 文档与报告格式

- 自动：PDF/docx 导入后可检索；导出的 docx / pptx 能被重新打开且含表格与结论
- 反例：加密 PDF 被拒且提示可读；导出失败不留半个文件；超大 docx 分块正常
- 手工：用 Word / PowerPoint 打开导出的文件

### P20 日常使用功能

- 自动：收藏重跑；重导入 drift 报告；双表对比；CSV 导出可被 pandas 读回且行列一致
- 反例：类型变更也能报 drift；不存在 `saved_id` 404；导出空结果集给可读提示
- 手工：收藏列表可直接重跑

### P21 性能与并发契约

- 自动：心跳延迟 p95 达标；10 并发无 5xx；基线对比不退化
- 反例：基线退化即失败；线程池打满时新请求排队而非 500
- 手工：两个问题同时问，互不卡死

### P22 多表关系与 join 校验

- 自动：候选推断有置信度；确认后跨表查询成功
- 反例：未登记 join 被拒并回传候选；低置信度不自动登记；跨数据集越权 join 被拒
- 手工：`/relations` 里能看出每条关系怎么来的

### P23 数据源直连

- 自动：SQLite 源同步成数据集；企业适配器四个函数用 mock 断言被正确调用
- 反例：`dsn_env` 缺失 → `capabilities` 显示未接入且不报错；连接失败给可读提示；连接串不出现在日志与响应里；适配器尝试 DDL 被拒
- 手工：同步后的数据集与上传文件行为一致（画像、版本、drift）

### P24 反馈闭环与成本配额

- 自动：踩入库；提升为 golden 行且格式合法；配额累计
- 反例：同一问题重复提升只留一条；超配额 429 且缓存命中仍可用；反馈里不含原始数据行
- 手工：`/quota` 与实际消耗一致

## 3. 专项测试（跨阶段，上线前必须全过）

1. **SQL 与越权**：DDL、DML、多语句、注释绕过、尾分号、写 CTE、跨库 ATTACH、超大结果、超时、不存在的表——共 10 条，全部必须被拒或安全中断
2. **提示注入**：三个来源（知识库文档、上传文档、MCP 返回值）× 三种攻击（「忽略以上指令」、伪装系统消息、要求导出全部数据）——行为不得改变，命中即记 `capability_log`
3. **沙箱逃逸**：`import os`、写文件、读他人文件、联网、死循环、巨量输出、分配大内存、fork 子进程——8 条全部必须被拒或被杀
4. **缓存正确性**：版本失效、换模型、改 prompt 版本、相似误命中边界（0.92/0.94）、缓存不存原始数据、并发写同一键不冲突
5. **多模型回退**：主模型 500 / 超时 / 返回非法 JSON / 空响应 / 全挂——五种情况都有确定行为
6. **流式**：帧序、`done` 唯一、断连取消、慢客户端、中途模型报错后仍能收尾
7. **MCP**：server 启动失败、调用超时、白名单外工具、server 中途崩溃、返回超大结果被截断
8. **认证与归属**：无 cookie、错密码、篡改 cookie、访问他人数据集、超频、超大上传
9. **数据源**：连接串泄漏检查、只读校验、增量水位、schema drift、同步中断不留半表
10. **多表 join**：未登记关系被拒、候选置信度边界、自连接、三表链式 join 只走已登记关系
11. **性能与并发**：见第 4 节阈值；另外测线程池打满时的排队行为与事件循环心跳
12. **评测体系自检（元测试）**：故意把一处代码改坏（例如把 SQL 守卫去掉），确认评测会变红——评测自己不红，等于没有评测

## 4. 非功能阈值（唯一权威数字，来自设计文档 4.14）

| 指标 | 目标 | 测法 |
|---|---|---|
| 单表 50 万行聚合 | p95 ≤ 1.5s | `bench/bench.py` |
| 缓存命中响应 | p95 ≤ 100ms | 同问题连问 20 次 |
| 流式首帧 | ≤ 1.2s | `/ask/stream` 计时 |
| 并发 10 请求 | 无 5xx | 并发压测 |
| 事件循环心跳延迟 | p95 ≤ 200ms | 心跳协程 + 压测同时跑 |
| SQL 执行 | 10s 超时 | 笛卡尔积查询 |
| 代码沙箱 | 20s 超时、输出 ≤ 1MB | 死循环 + 巨量输出 |
| 评测 | sql 通过率 ≥ 0.80、忠实度 ≥ 0.95、降级率 ≤ 0.05 | `app.evalharness` |
| 每日成本 | ≤ `QUOTA_DAILY_COST_USD` | `/quota` |

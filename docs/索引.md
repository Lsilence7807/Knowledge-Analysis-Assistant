省 token 读法：按上表「先小后大」的顺序读；`系统总体设计.md` 只读你要做的那段（§5 定位 → §4 对应契约小节）。整份读设计文档约 16k token，读一段约 2-3k。

项目根还有：`启动.cmd`（双击一键起网页端：建环境 + 装依赖 + 开页面）、`AGENTS.md`（编码约束与阶段流程，自动加载）、`requirements.txt`（每行带 why 与阶段）、`pyproject.toml`（ruff + pytest，唯一质量门配置）、`config/local.json`（页面写入的本机密钥，gitignore 挡住）、`README.md`（面向使用者的快速上手）。

文档里的命令写成 `python -m pytest ...`，实际指项目虚拟环境里的解释器，本机写法 `& .\.venv\Scripts\python.exe -m pytest ...`。
